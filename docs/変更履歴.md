## 2. LPトップの購入ボタン

- 「思い切って本当の自分と向き合ってみる」を「今すぐ本当の自分と向き合ってみる」に変更しました。
- クリック時に料金欄の「今すぐ有料プランに進む」と同じCheckoutButtonを使用するようにしました。従来の料金欄へのスクロールから、購入処理へ直接進む導線に変更しています。
- 未ログインの場合は、ログイン後の戻り先を `/checkout/start` に指定します。
- ボタン上部に「有料プランお申込み」の吹き出しを追加しました。
- 吹き出しは黄色の背景（#ffdc54）・濃紺の文字（#142348）・明るい縁取りと影を使用します。
- 2.8秒周期で軽く跳ね、拡大・傾きを加えるアニメーションを設定しました。動きを減らす設定ではアニメーションを停止します。
- 吹き出しは未ログイン時・無料ユーザーのログイン時だけ表示します。有料ユーザー、認証確認中、プラン確認中・取得失敗時には表示しません。
- 吹き出しとボタンを `aria-describedby` で関連付け、複数箇所でもIDが重複しないようReactのuseIdを使用しました。

対象：`app/components/HeroSection.tsx`、新規 `app/components/HeroPurchaseCta.tsx`、`app/components/CheckoutButton.tsx`、`app/globals.css`

- 無料側のボタンは既存のDiagnosisCtaを使用します。

## 4. ログイン後の購入中継画面（/checkout/start）

- サーバーで会員情報のプランを確認します。有料ユーザーは購入準備画面を表示せず、`/dashboard` に移動します。
- 無料ユーザーは購入準備画面を表示し、既存の自動開始処理でStripe Checkoutへ進みます。
- 未ログインの場合はログイン画面へ移動します。
- 会員を特定できない場合、または会員情報がない場合はダッシュボードへ移動します。
- クライアント側でも、自動開始時に有料プランと判定された場合はダッシュボードへ移動する処理を追加しました。

対象：`app/checkout/start/page.tsx`、`app/components/CheckoutButton.tsx`

## 5. プラン情報の取得と購入ボタン

- 全ユーザー共通のプランキャッシュを廃止しました。
- 会員IDまたはメールアドレスごとに、取得中のリクエストだけを共通化します。完了後は保持せず、アカウントが変わった場合に再取得します。
- プラン取得は `cache: "no-store"` を指定します。
- 取得失敗を無料プラン扱いにせず、エラー状態として保持します。購入ボタンは契約状態を確認できない旨を表示し、購入開始を止めます。
- 認証確認中は購入ボタンを無効化します。
- ボタンの契約済み文言を指定できる `subscribedLabel`、吹き出しの参照先を指定できる `describedBy` を追加しました。

対象：`app/hooks/useUserPlan.ts`、`app/components/CheckoutButton.tsx`

## 6. 決済キャンセルページ（/checkout/cancel）

- 「料金ページへ」ボタンと不要になったアイコンのimportを削除しました。
- 「トップページへ」のリンクを `/?skipOpening=1#top` に変更し、演出・扉を省略してLPトップを表示します。リンクの先読みも無効化しています。
- 演出省略は、元のソースにあるOpeningSequenceの機能を利用しています。

対象：`app/checkout/cancel/page.tsx`

## 7. 無料ユーザーのダッシュボード（/dashboard）

- ボタンは「無料プラン」の表示の右隣に配置しています。スマホでは中央揃えを基本とし、幅が足りない場合は折り返します。
- LPと同じCheckoutButtonを使用し、同じ購入処理へ進みます。
- 最終的な配色はゴールドの背景（#ffe985 → #ffd044）・濃紺の文字（#142348）です。白い外枠、縁取り、影で強調しています。
- 当初の40px・14pxから、最小高さ48px・文字16px・左右余白26pxへ一回り大きくしました。
- 有料ユーザーのプラン表示・解約操作は元の表示を維持しています。

対象：`app/dashboard/page.tsx`、`app/globals.css`
