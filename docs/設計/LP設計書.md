# AIキャリア診断サービス LP設計書

## 1. 目的とスコープ

5問への回答からAIがキャリアロードマップを提案するサービスの価値を短時間で理解してもらい、診断開始CTAの押下につなげる。Stage1ではLPのみを実装し、認証・質問回答・AI分析・結果表示は実装しない。

## 2. デザイン方針

- 白から淡いブルーの背景を基調に、濃紺の文字で信頼感と可読性を確保する
- CTAだけに青系グラデーションを使い、画面内の主行動を明確にする
- 大きな余白、短いコピー、細い罫線で情報の階層を整理する
- ヒーロー右側に「5問からロードマップへ」の抽象ビジュアルを置き、サービスの仕組みを視覚化する
- 角丸や影は控えめにし、カードは枠線と背景差で整理する

## 4. セクション詳細

### ヘッダー・ヒーロー

- サービス名と「5 QUESTIONS」のラベルを表示する
- H1は指定コピー「5問でわかる、あなたのキャリア」
- サブコピーはAI分析とロードマップという便益を明示する
- CTA下に「約3分」「診断機能は準備中」を明記する
- PCは2カラム、タブレット以下は1カラムに組み替える

### 特徴

- 3項目をカード化し、番号・短い見出し・説明を表示する
- PCは3列、タブレットは可変、スマートフォンは1列とする
- 根拠のない精度や実績値は掲載しない

### 診断の流れ

- 回答、分析、結果の3ステップを順番に表示する
- PCでは横方向、スマートフォンでは縦方向に配置する
- 接続線は装飾扱いとし、線がなくても順序を理解できる構造にする

### 下部CTA

- 濃紺背景でページ全体に明確な終点を作る
- ヒーローと同じCTAを配置し、Stage1ではSnackbarで準備中を通知する

### フッター

- サービス名と著作権表示のみを掲載する
- 未作成の規約ページなどへのリンクは置かない

## 5. レスポンシブとアクセシビリティ

- 基準幅：スマートフォン 375px、タブレット 768px、PC 1200px以上
- CTAの高さは52px以上、キーボードフォーカスを明示する
- H1は1ページに1つ、各セクションはH2、カード見出しはH3とする
- 装飾SVGは`aria-hidden`とし、主要情報はテキストとしてDOMに保持する
- `prefers-reduced-motion`では不要なトランジションを抑制する
- 本文へのスキップリンクを実装する

## 7. CTA仕様

- ラベル：「無料で診断を始める」
- Stage1：画面遷移させず「診断機能は現在準備中です。Stage2以降で公開予定です。」と表示する
- Stage2以降：認証または診断開始画面への遷移に差し替える
